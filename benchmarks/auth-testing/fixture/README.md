# Acme Notes

A small notes app: sign in, read and add notes, sign out.

- `npm start` serves it on http://127.0.0.1:3000 (set `PORT` to change).
- `npm test` runs the unit tests (`node:test`, in `test/`) and the browser tests
  (Playwright, in `e2e/`).

Demo account: `alice` / `correct-horse-battery`.
